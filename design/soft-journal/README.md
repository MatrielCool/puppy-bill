# 小狗账单 · 柔彩日记

`index.html` 是最初的独立视觉样稿，不读写账本。用户确认后，配色、字体和图标已接入现有 React 应用的五个页面及弹层；`implemented.html` 加载真实应用，操作会写入当前浏览器账本。

## 参考

- https://www.pinterest.com/pin/827536500330292223/
- https://www.pinterest.com/pin/1145181011536591722/

两张参考展示同一套日记界面的不同场景。借鉴暖灰底、麦芽黄色主卡片、灰粉和浅紫辅助卡片，以及克制的圆润线条。下列色值为重新搭配的设计值，并非宣称从图片精确采样。图标和小狗场景为本项目新绘制的 SVG，没有复制参考图的素材。

## 制作路径

先用 HTML/CSS 制作可运行的真实尺寸样稿，再将确认后的色值、组件和图标迁入 React。SVG 用于功能图标及品牌图形。Figma 可用于后续协作交接。

样稿以浅色校准参考风格。正式应用保留原有跟随系统的深色模式，另配低亮度色块。暖灰白为主背景，麦芽黄用于账单汇总，浅紫用于待收款，鼠尾草绿用于预算。语义色单独定义；浅色按钮使用深字，避免黄底白字对比不足。

## 图标

- 24 × 24 统一网格，主要描边 1.6px，圆头、圆角。
- 深棕灰轮廓；每个图标最多一种辅色。
- 未选中时减少填充，保留轮廓对比度；选中时用柔和底色及填充强调。
- 导航用 21–24px，分类 24px，较大的图形需按使用场景复核。
- `icons.svg` / `icons/` 保留最初样稿的图标；正式应用以 `src/ui/iconPaths.mjs` 为唯一图标源，补齐学习、人情、红包及备份操作等图标。两者的样稿用途与生产用途分开。
- 修改后运行 `node design/soft-journal/export-icons.mjs` 重新导出。

## 预览

原始样稿可用静态 HTTP 服务运行。样稿保存按钮仅演示，不写入数据。

正式应用运行 `npm run dev`，访问 `/puppy-bill/`；实际页面对照板位于 `/puppy-bill/design/soft-journal/implemented.html`。对照板只是预览入口，不改变应用路由或存储逻辑。

## 正式应用的字体与排版

- 中文：iOS 优先使用苹方，Windows 使用微软雅黑，其他设备使用系统无衬线字体。正文 15px，标签 12–13px，主标题 25px / 600 字重；不把整页文字统一加粗。
- 数字：本地打包 Manrope 可变字体（约 25KB），金额使用 500–600 字重及 `tabular-nums`，大金额轻微收紧字距。字体与应用一同离线缓存。
- 输入框保持至少 16px，避免 iOS 聚焦时自动放大。320px 小屏压缩装饰标题与留白，保留四行数字键盘。
- 字体来自 [Google Fonts / Manrope](https://github.com/google/fonts/tree/main/ofl/manrope)，许可证保存在 `src/assets/fonts/OFL-Manrope.txt`。
- 仅调整展示组件、样式及图标资源；数据库、金额计算、备份和待入账业务逻辑保持原样。

## 小狗图形细化

2026-10-19，用户通过截图确认采用 `puppy-round.png` 中间的圆脸版本。已将后续五官试验稿和简化稿替换回这一版。项目总交接见根目录 `HANDOFF.md`。

品牌图形的轮廓与配色集中在 `src/ui/puppyArtwork.mjs`：饱满圆脸、短圆垂耳、奶油色脸颊、灰褐色耳朵、小椭圆眼睛，保留淡色椭圆口鼻块。24–30px 使用简化图形，40px 以上增加一侧眼斑、口鼻色块和鼠尾草绿项圈；没有眼神光、腮红和双瓣嘴套。页面头像、预算中心、导航和 PWA 主屏图标共用这一份几何源。

`reference/user-approved-round.jpg` 保存用户确认的截图；`reference/puppy-approved.svg` 保存已确认头像的矢量基准。恢复时核对过 SVG，几何、颜色和描边完全一致。`puppy-refinement.html` / `puppy-approved.png` 是当前对照板；`puppy-mark.svg` / `puppy-small.svg` 为独立可用的矢量导出。`puppy-features.png` 和 `puppy-flat.png` 只保留为历史试验，不能当成最终设计。

重新生成主屏图标、独立 SVG 和对照板：

```bash
npm run icons
node design/soft-journal/export-puppy-preview.mjs
```

此脚本及其输入已放进项目目录，不依赖被 Git 忽略的 `scratch/`。小狗细化后已检查浅色、深色下的 24、30、44、64px 显示及真实页面效果。
